## `05 / Getting Started`

### Prerequisites

- Node.js and npm
- MongoDB connection
- Postman
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Ahsin18/Api-Testing-.git
```

**2. Navigate into the project**

```bash
cd Api-Testing-
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file using the provided `.env.example` file and configure your database connection.

**5. Start the server**

```bash
node server.js
```

**6. Test the API**

Open Postman and send requests to your local server.
